## run core validator

```
set define_path=%data_path%\define.xml
set report_path=%data_path%\..\validation-report-core
set std=sdtmig
set std_vers= 3-4
.\core.exe validate -s %std% -v %std_vers% -d "%data_path%" -of JSON -dxp "%define_path%" -o "%report_path%"
```
